# 2. 各モデルの「仕様」と「時短×リッチ化」チートシート (確定版)

## **item-002-Piano (Keyboard)**

* **背面IO:**
* **リセス (窪み):** 背面の一部を四角くブーリアンで凹ませ、黒いパネルを配置。
* **端子構成:** OUTPUT (L/Rの丸穴)、USB (四角)、DC IN (小丸穴) の3種のみ配置。

* **仕上げ:** 黒鍵は白鍵に「めり込ませる」。不要な底面ポリゴンは削除済みを確認。

## **item-003-can_coffee (修正：質感分離)**

* **形状:** 側面は凹凸なしの円柱。蓋と底の接合部分（リム）の「絞り込み」をリアルに。
* **質感 (重要):**
* **Metallic Map:** 白黒画像を作成し、**リム部分は「1.0 (白)」、ラベル部分は「0.0 (黒)」**に塗り分ける。
* **UV:** 円柱展開し、ラベル画像を正しく貼り付ける。

## **item-004-acoustic_guitar (修正：穴の奥行き)**

* **弦・ピン:** 完全撤去。
* **サウンドホール:**
* 黒い円テクスチャ**ではなく**、実際にブーリアンで**穴を開ける**。
* 内部に「底の浅い黒い円柱」を配置し、物理的な奥行きを作る (覗き込んだ時の説得力重視)。

* **ボディ:** 表面の木目は彩度を下げ、経年劣化を表現。

## **item-006-Camera (修正：文字の選別)**

* **レンズ文字:**
* "35mm F2" などの**大きな文字のみメッシュ化**。
* 細かいスペック文字はテクスチャ (Normal Map) で処理し、頂点数を節約。

* **皮シボ:** ノイズテクスチャをバンプ→ノーマルマップとしてベイク。

## **item-007-Game_Boy (修正：カセットの向き)**

* **カセット:**
* **向き:** ラベル面が**外側（背面のプレイヤー側から見える向き）**になるように挿す。
* タイトル: 「テトリス」等のラベルが見える状態で固定。

* **背面:** スピーカー穴 (ブーリアン)、グリップ用スリット作成。

## **item-008-Lantern (修正：ガラス軽量化)**

* **形状:** 下半身(オイル) × 上半身(ガソリン) のキメラ。
* **ガラス (R3F対策):**
* 重い `Transmission` は避け、**`Alpha Hashed` (ディザリング透過)** を使用。
* または「中身がボヤけて映っているテクスチャ」を `Emission` で貼るフェイク表現を採用する。

## **item-009-Family_Photo**

* **写真:** 画像テクスチャを使用。
* **演出:** R3F側で「逆光で見えにくい」シェーダーを当てるため、テクスチャ自体は普通のものでOK。
