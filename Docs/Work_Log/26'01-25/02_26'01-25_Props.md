# 実装計画書 (2026-01-25) - React Hooks 訓練 (Props)

## Phase 1.5: React Hooks Training (Props & Events)

### 概要
次は **「Props (データの受け渡し)」** と **「Event (イベント通知)」** を習得します。
先ほど作ったカウンターの数字によって、「3Dキューブの色」が変わるように連携させます。

### 技術的翻訳 (Vanilla JS -> React)

| Vanilla JS | React (Props) |
| :--- | :--- |
| `function child(arg1) { ... }` | `<Child arg1={value} />` |
| 親が子の変数を直接書き換える | **禁止** (親からデータを「渡す」だけ) |
| 子が親に通知 (`callback()`) | 子のイベントで親の関数を呼ぶ |

### 実行手順

#### 1. `app/components/Scene.tsx` の改修 (完了)
親 (`page.tsx`) から `color` というデータを受け取れるように改造しました。

#### 2. Stateのリフティング (修正作業)
私が出した指示に不備があり、現在「親」と「子」で別々の変数を持ってしまっています。
これを解消するため、**「親 (`page`) が全ての変数を管理し、子 (`Counter`) はそれを表示・操作するだけ」** という形に書き換えます。

**Step A: `app/components/Counter.tsx` の修正**
自分自身のStateを削除し、親から「値」と「更新関数」をもらう形にします。

```tsx
'use client'

// useStateはもう不要なのでimportから削除してOKですが、残っててもエラーにはなりません。
// import { useState } from 'react' 

// Vanilla JS: function Counter(props) { let count = props.count; ... }
// React: 引数で count と setCount を受け取る
type CounterProps = {
  count: number;
  setCount: (n: number) => void;
}

export default function Counter({ count, setCount }: CounterProps) {
  // 削除: const [count, setCount] = useState(0) 
  // ↑ 親からもらうので、自分自身で持つ必要がなくなりました。

  const handleClick = () => {
    // 親から預かった「setCount」を実行する
    setCount(count + 1)
    console.log(`Current Count: ${count + 1}`)
  }

  return (
    <div className="absolute top-4 left-4 z-10 bg-white/10 p-4 rounded-lg backdrop-blur-md text-white">
      <h2 className="text-xl font-bold mb-2">Counter</h2>
      <div className="flex items-center gap-4">
        <span className="text-3xl font-mono">{count}</span>
        <button 
          onClick={handleClick}
          className="px-4 py-2 bg-blue-500 hover:bg-blue-600 rounded transition"
        >
          Count Up
        </button>
      </div>
    </div>
  )
}
```

**Step B: `app/page.tsx` の修正**
`Counter` に自分の持っている `count` と `setCount` を渡してあげます。

```tsx
'use client'

import dynamic from 'next/dynamic'
import Counter from './components/Counter' // .tsxは不要
import { useState } from 'react'

const Scene = dynamic(() => import('./components/Scene'), { ssr: false })

export default function Home() {
  const [count, setCount] = useState(0)

  // カウントが偶数なら赤(red)、奇数なら青(blue)にするロジック
  const boxColor = count % 2 === 0 ? 'red' : 'blue'

  return (
    <main className="h-screen w-full bg-black relative">
      {/* 修正: 親の count と setCount を子に貸してあげる */}
      <Counter count={count} setCount={setCount} />
      
      <Scene color={boxColor} />
    </main>
  )
}
```
