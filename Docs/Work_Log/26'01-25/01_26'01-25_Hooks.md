# 実装計画書 (2026-01-25) - React Hooks 訓練

## Phase 1.5: React Hooks Training (Unity概念翻訳)

### 概要
Unityエンジニアが最もつまづきやすい **「State (状態管理)」** を習得します。
単純なカウンターアプリを作成し、変数の書き換えがどう画面に反映されるかを体感します。

### 技術的翻訳 (Unity -> React)
| Unity (C#) | React (TypeScript) |
| :--- | :--- |
| `private int count = 0;` (メンバ変数) | `const [count, setCount] = useState(0)` |
| `count++;` (直接書き換え) | `setCount(count + 1)` (関数経由で更新) |
| `Update()` で `text.text = count;` | **自動同期** (Stateが変われば勝手に再描画) |

### 実行手順

#### 1. `app/components/Counter.tsx` の作成
2DのUIオーバーレイとして、画面左上にカウンターを表示します。

**実装コード案 (写経用):**
※スキル向上のため、以下のコードをコピペせず、手動で入力してください。
```tsx
'use client' // Security: このファイルはブラウザに送信されます。APIキーや秘密情報は絶対に書かないでください。

import { useState } from 'react'

export default function Counter() {
    // Vanilla JS: let count = 0;
    // React: 変数(State)と「値を更新する関数(setCount)」がセットになっています。
    // Security: この変数はクライアント側(メモリ上)にのみ存在します。
    //          ユーザーがブラウザのツールで値を改変可能なので、重要な判定(課金など)にそのまま使ってはいけません。
    const [count, setCount] = useState(0)

    const handleClick = () => {
        // Vanilla JS: count++; document.getElementById('Display').innerText = count;
        // React: setCountを使うだけで、変数の更新と画面の書き換え(再描画)が自動で行われます。
        setCount(count + 1)
        console.log(`Current Count: ${count + 1}`)
    }

    return (
        // Vanilla JS: HTMLを文字列で document.body.innerHTML += ... するのに近いです。
        // Security: ReactはデフォルトでXSS(スクリプト注入攻撃)を防ぎます。
        //          ユーザー入力などを表示しても、勝手にスクリプトが実行されることはありません。
        <div className="absolute top-4 left-4 z-10 bg-white/10 p-4 rounded-lg backdrop-blur-md text-white">
            <h2 className="text-xl font-bold mb-2">Counter</h2>
            <div className="flex items-center gap-4">
                {/* Vanilla JS: <span id="display"></span> の中身を書き換える必要なし。変数を置くだけ。 */}
                <span className="text-3xl font-mono">{count}</span>
                <button 
                    onClick={handleClick}
                    className="px-4 py-2 bg-blue-500 hover:bg-blue-600 rounded transition"
                >
                    Count Up
                </button>
            </div>
        </div>
    )
}
```

#### 2. `app/page.tsx` への配置
作成した `Counter` コンポーネントをメインシーンに重ねて表示します。

**変更案:**
```tsx
'use client'

import dynamic from 'next/dynamic'
import Counter from './components/Counter' // 追加

const Scene = dynamic(() => import('./components/Scene'), { ssr: false })

export default function Home() {
  return (
    <main className="h-screen w-full bg-black relative"> {/* relative追加 */}
      {/* 2D UI Overlay */}
      <Counter />
      
      {/* 3D Scene */}
      <Scene />
    </main>
  )
}
```
