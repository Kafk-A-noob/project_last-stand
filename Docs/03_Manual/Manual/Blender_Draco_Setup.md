# Blender 4.2+: Draco圧縮を有効にする方法

Blender 4.2から、glTFエクスポーターは「コア機能」から「拡張機能 (Extension)」として分離・管理されるようになり、**初回セットアップや更新が必要**な場合があります。

## 手順 (Knowledge)

1. **インターネット接続を確認する** (拡張機能をダウンロードするため)
2. **編集 (Edit) -> プリファレンス (Preferences)** を開く。
3. 左側のメニューから **「Get Extensions (拡張機能を入手)」** を選択。
4. 右上の検索バーで `glTF` と入力。
5. **「Import-Export: glTF 2.0 format」** が表示されるので確認。
    * すでにインストール済みなら **「Installed」** タブにあるか確認。
    * **「Update」** ボタンがあれば押して最新にする。
6. **重要:** 右側の「▽」を開き、**「Install Dependencies」** や **「Wheel」** のような追加ダウンロードボタンがないか確認する。
    * Draco圧縮には `draco_encoder` などのバイナリ等が必要なため、ここでの承認が必要な場合があります。

## もしそれでも出ない場合

手動でアドオン設定を確認します。

1. **プリファレンス -> アドオン (Add-ons)** を開く。
2. `glTF 2.0` を検索 -> 展開。
3. 設定の中に **「Draco Compression」** に関する警告や「Download」ボタンがないか探す。

## なぜこの知識が必要か？

Web3Dではファイルサイズがロード時間に直結します。
Draco圧縮を使うと、3Dモデルのサイズを **1/5 ~ 1/10** にまで劇的に小さくできます。
「必須ではないが、本番環境(Production)では実質必須」の技術です。
